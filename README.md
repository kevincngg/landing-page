# Landing Page

This project is a custom landing page built as part of The Odin Project Foundations curriculum.

I used HTML and CSS to practice:

- Flexbox layouts
- Header and navigation styling
- Hero sections
- Image and text alignment
- Responsive-style spacing
- Quote sections
- Call-to-action sections
- Footer design

I customized the project into a travel-themed landing page focused on cities I would like to visit.

## Features

- Travel-themed hero section
- Navigation links
- City photo gallery
- Travel quote section
- Call-to-action signup section
- Footer
- Custom colors, typography, spacing, and layout using Flexbox

## Technologies Used

- HTML5
- CSS3
- Flexbox
- Google Fonts
